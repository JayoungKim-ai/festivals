# 전국 축제 정보 검색 서비스 — 작업 목록

`docs/DEVELOPMENT_PLAN.md`와 `docs/PRD.md`를 기준으로 한다.

### M. 일자별·지역별 검색 화면

지역 필터(기존 `region`)와 함께 쓸 수 있게 한다.

#### M-1. 백엔드 — 일자·월 기준 조회 API

- [x] 월별 일자별 축제 건수 API 설계 (`year`, `month`, 선택 `region`)
- [x] 해당 월의 각 날짜에 대해, `start_date`~`end_date`에 포함되는 축제 건수를 집계하는 로직 구현
- [x] 특정 날짜의 축제 목록 API 설계·구현 (`date`, 선택 `region`, 좌표 포함)
- [x] 날짜·지역 동시 필터가 되도록 조회 로직 확인
- [x] (선택) Swagger(`/docs`)에서 월별 건수·일자별 목록 API 동작 확인

#### M-2. 프론트엔드 — 화면·달력

- [x] 일자별·지역별 검색 페이지 라우트 추가 (예: `/calendar`)
- [x] 헤더에 해당 메뉴 추가
- [x] 월 선택 UI 구현 (이전/다음 월 또는 월 선택)

- [x] 지역 선택 UI를 달력 화면에도 적용 (전체/특정 시도)
- [x] 월·지역 변경 시 일자별 건수 다시 조회

- 현재 기준 시작점: `backend/main.py`(health·CORS·SQLite 엔진), `frontend/src`(연결 확인 UI)
- 작업 시 `docs/TASKS.md`의 해당 체크박스를 함께 업데이트한다.
- MVP(A~I)를 모두 끝낸 뒤에만 J~L을 진행한다.
- 일자별·지역별 검색(M)은 J~L 완료 후 진행한다.
- 페이지네이션(N)은 M 완료 후 진행한다.
